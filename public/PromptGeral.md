# Prompt Geral
- Site será para uma empresa de serviço de modelagem 3D e detalhamento tecnico

- Você atuara como um Desenvolvedor Full Stack senior. Quero que tenha boas praticas como programador, entre elas aplique o clean code, principios de SOLID. Vamos fazer tudo isso com React, JS, HTML e CSS.

- Quero ter uma aba de navegacao e um rodape padrao para todo o site.

- Separaremos o site em praticamente 3 paginas. 

## Inicio 
- Uma div principal, como se fosse para um banner com uma frase apresentando a empresa e dois botões:
- Faça seu Orçamento -> Envia para pagina contatos onde terá um formulário que envia direto para o email da empresa.
- Saiba Mais -> Envia para página serviços

## Serviços
- Uma parte superior com uma descrição de que tipo de empresa somos.
- Diversos cards com imagem de fundo com um titulo. Quando passamos o mouse sobre o card, aparece uma descrição breve do serviço.
- 4 cards por linha. 
## Contato
- Pense em algo.

O site deve transmitir a sensação de profissionalismo e ao mesmo tempo ter um estilo minimalista. Algo bem atual e inovador.

As cores principais pode utilizar cinza, cinza grafite, preto e branco.

- onde tiver imagem, seja de logo ou outra coisa do tipo, coloque uma imagem do placeholder

Faça a base desse site e deixe bem organizado para que eu consiga fazer manutenção posteriormente
